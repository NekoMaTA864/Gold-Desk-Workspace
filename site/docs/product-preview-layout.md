# 面向使用者的本地版面調整

模式：Redesign · Preserve。沿用深藍／金色、Segoe UI／微軟正黑體、7–11px 圓角及既有 GD 字標。

使用者為黃金交易新手或略有經驗者；主流程是建立草稿、核對、確認模擬委託。設計設定為視覺變化 3/10、動態 1/10、資訊密度 6/10、素材需求 1/10、品牌保留 10/10；具體採縮減常駐資訊、維持三欄與收合式依據，未引入新視覺素材。

## 畫面改變

- 頂端只常駐主要導覽、模式狀態及工作台；資料來源展開查看，版型與展示工具收在同一入口。
- 註冊登入流程仍保留，入口以免註冊模擬體驗為主，清楚標示帳號是暫存展示。
- 檢查視窗先呈現訂單、風險、提醒與證據摘要；觸發提醒、無法評估的規則和風險警示直接顯示。五區依據可展開，操作列保持可見。
- 工作台可直接查看與篩選委託紀錄，取消待成交單，或另行開啟回放。最近一筆提示可收起，紀錄仍在。
- 重要文字維持 13–16px，次要資訊以 12px 為主，補上鍵盤焦點與減少動態設定。

## 保留的行為

三個主要頁面、版型網址與儲存鍵、四項提醒、至少 8 字元的展示密碼、既有模擬計算及確認流程保留。沒有接入新的案例演算法、券商送單方法或帳號後端。

展示情境只預覽提示，不注入 API。cTrader 唯讀資料與合成帳戶分開，無可用帳戶資料時顯示「—」。

主要回歸關注為：取消檢查後欄位保留、確認委託需明確操作、紀錄篩選與取消、原版型參數可用，以及各對話視窗可用 Escape 關閉。樣式集中在 `src/product-experience.css`，與資料運算分開。
