# Gold Desk 桌面流程原型

這是 E 負責的前端展示稿，與團隊正式網站分開。畫面中的報價、K 線、歷史案例及證據狀態皆為**合成資料**；按鈕只開啟摘要，沒有送單或真實行情連線。

## 開啟方式

在本資料夾執行：

```powershell
& ..\.venv\Scripts\python.exe -m http.server 8765
```

瀏覽 `http://127.0.0.1:8765/`。此稿使用原生 HTML、CSS、JavaScript，無需安裝套件。正式整合時可將各面板移植到團隊現有的 React／Vite 前端。

## 可操作的流程

1. 切換歷史回放、即時看盤與券商模擬，查看報價來源及連線標示。
2. 切換正常、無相似案例、說明生成失敗、報價過期、券商斷線五種展示情境。
3. 調整方向與手數，勾選三種提醒條件；提醒結果會立即更新。
4. 開啟五區確認摘要，檢查部位、規則、案例、證據充分性、說明與限制。

## 與正式系統的界線

- 此稿的案例匹配與證據狀態由固定展示資料決定，不是實際搜尋結果。
- 價格相對 MA20 與 K 棒形態是固定展示值；正式版需要 B／C 提供有時間戳的數值與計算定義。
- 「即時看盤」圖表、可用於確認的券商報價、真正的委託服務必須分開接入。
- 目前沒有登入、權限或實際下單；確認按鈕僅表示完成畫面檢查。
- 本輪優先完成桌面展示與資料契約；手機版暫緩。

Agent 的資料與責任分界見 [agent-feasibility.md](../docs/agent-feasibility.md)。
