# Gold Desk 展示腳本

更新：2026-10-28。公開Pages與本機完整後端是不同模式。不要用假回報代替券商結果。

## 現在可展示的模擬流程（約5分鐘）

1. 訪客入口進入交易對話，指出合成回放時間、模擬帳戶與外部TradingView參考來源。首頁不預設大看盤。
2. 開使用指引，說明買價、賣價、手數與點差。展示帳號不是正式登入，也沒有券商權限。
3. 輸入「買進黃金0.10手」送出，核對風險、提醒、案例、證據及說明五區；先取消一次，確認持倉仍為0。草稿不等於成交。
4. 提醒條件設定本筆手數大於0.05手，預覽並確認儲存。重新檢查0.10手，核對觸發原因；提醒不代替確認。
5. 展開波動參考，指出固定2026快照、期貨來源及與2025回放不同時點的獨立示範標示。預算試算不改草稿，也不是損失上限。
6. 查看案例比較條件與資料限制。公開版已有授權公開的真實歷史案例；查詢行情、帳戶及成交仍為合成。歷史結果不是新交易勝率。
7. 確認本機模擬成交，查看1筆持倉；平倉需再次確認。到歷史回放的下單／成交紀錄查看進出場價格與本機模擬標示。
8. 展示連線狀態與390px操作；結束時移除自己新增的測試規則，不清除他人設定。

找不到真實零案例查詢時，不關閉資料製造零案例。可另外打開dev/review-preview.html，明示是合成驗收頁，展示零案例、規則未接入、錯快照；不當成真檢索證據。

## 後端接通後才可展示（待A–D共同驗收）

1. 正式登入，核對角色與團隊DEMO帳戶；後端拒絕一般使用者送單。
2. 顯示cTrader報價時間及商品規格，未就緒／過期不得以回放價格代替。
3. 建立正式草稿，核對同一快照的五區；提醒與證據須由後端實際提供。
4. 僅由帳戶擁有者完成真正DEMO確認／平倉；顯示券商編號與回報，分清已接受、部分成交與成交。
5. UNKNOWN查原委託並對帳，不重送；共同驗收重連、持久日誌及多人資料隔離。

服務未就緒就展示第一段，不宣稱正式登入、跨裝置同步或券商交易已完成。真實資金不在範圍。
