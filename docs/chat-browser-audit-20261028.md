# 公開模擬交易對話實測與修正

在側邊瀏覽器的本機 Pages 工作台實際輸入，沒有啟用 Groq，也沒有確認新的模擬或券商成交。

| 輸入 | 原本觀察 | 修正後瀏覽器重測 |
| --- | --- | --- |
| 我想買進黃金 | 通用行情，沒有補問手數 | 明確追問手數並示範完整指令 |
| 如果改成賣出0.2手呢？ | 誤導向提醒設定 | 說明是討論，不修改草稿；指出基本助手限制 |
| 買進-0.1手 | 誤讀成正0.1並開核對，已取消 | 明確拒絕，沒有核對視窗 |
| 買進0.1手或賣出0.2手 | 新增保護 | 要求一個方向，不建立草稿 |
| 改成0.2手 | 原程式會借用選取方向 | 引導側欄編輯或完整重新描述，不猜上一筆 |
| 手數是什麼 | 新增基本說明 | 說明數量、盎司與券商規格界線 |
| 單筆超過0.1手提醒我 | 提醒提案 | 正常顯示待儲存提案，本輪已取消 |
| 買進黃金0.10手停損2910停利2950 | 合法完整指令 | 草稿方向、手數及兩個價格正確，本輪已取消 |

新增demoChatIntent.ts作公開展示的保守解析：負數、科學記號、千分位、破損小數、多方向／手數／保護價、詢問與假設、非支援限價／英文保護標籤，都不靜默轉成另一種委託。只改前端文字意圖與訊息，不改風險計算、檢索、確認或後端解析。personalRules只接明確規則意圖，不再搶走一般假設交易與否定語句。

此模式仍不是完整自由對話：不能沿用上一則補齊欄位，也不提供完整假設比較或預測；需要表單完成或等待正式助手服務。正式模式原interpret API不變。

183項前端測試、TypeScript及兩種建置通過。30句清單P10改為預期零手數明示回覆且不建草稿，保持不產生持倉的驗收要求。測試畫面與對話留於本機，未提交／推送。Vite熱更新會重建公開模擬引擎；其持倉並非持久帳戶資料，不能拿來驗證正式持倉保存。
