# 工作台版型比較：組員試用稿

同一個網站、同一份合成回放資料，提供兩種調整方式。切換按鈕會更新網址參數，連結可直接分享；版型與大小偏好另外存在試用者自己的瀏覽器。公開入口：[Gold Desk 展示網站](https://nekomata864.github.io/Gold-Desk-Workspace/)。

## 比較入口

在 `https://nekomata864.github.io/Gold-Desk-Workspace/` 後加入下列參數：

| 連結參數 | 可看到的安排 |
| --- | --- |
| `?layout=preset&preset=standard` | 標準工作台：左大盤、右下單與對話分頁、下方帳戶資料 |
| `?layout=preset&preset=chart-focus` | 大盤置頂、下方左持倉、右對話助手 |
| `?layout=preset&preset=positions-right` | 左大盤、右側上方持倉與下方下單／對話／提醒 |
| `?layout=resize&preset=standard` | 標準安排，加上左右分隔線和圖表高度分隔線 |
| `?layout=resize&preset=chart-focus` | 大盤置頂安排，加上下方左右與圖表高度分隔線 |

畫面選項稱為「固定版型」與「自訂大小（拖拉）」；後者只改變面板大小。桌面寬度超過 1100px 時顯示左右分隔線；較窄視窗會改成單欄，避免把圖表或持倉壓得無法閱讀。

## 試用時可問組員

1. 操作回放時，哪種版型最容易同時看到 K 線、部位與對話？
2. 有沒有哪個面板太窄或太高？拖分隔線是否比切換固定版型方便？
3. 拖分隔線會不會誤觸 K 線操作或輸入欄？是否需要保留「重設大小」？

## 目前界線

- 這是同一個 React 頁面的兩種版型模式，不需要維護兩套交易邏輯。
- 面板位置由預設版型決定；拖分隔線只調整大小，不能把任意面板搬到任意位置。
- 提醒條件和下單、對話助手共用右側分頁；交易前分析保留在大盤卡片下。若試用者明確需要完全獨立的模組，再進一步拆成可重新排列的面板。
- 回放圖表會隨容器變化；TradingView 外部圖表仍僅供看盤，不能作為回放委託價格。
