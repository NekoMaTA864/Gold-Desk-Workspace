# 助手回答原則：介面呈現與來源

整理來源為 Kuan 的 Gold-Trading-Project / 5bf88de（2026-10-27），backend/live_assistant.py 的 LIVE_SYSTEM、writer_facts、render_sections、render_model_sections、respond_context，以及 docs/case_scenarios_20261027.md。這是規則說明的介面整理，並非移植新後端功能。

| 使用者能理解的原則 | 程式／規則的實際責任 |
| --- | --- |
| 數字由程式計算 | 模型接白名單事實、token與程式關係；精確數值由程式填回，不讓模型重新計算 |
| 說明要有依據 | 段落須引用本次事實ID；拒絕未知ID、未知token、部分裸寫數字與不允許宣稱。合格引用但不合格段落可由程式補正，全失敗則退回程式摘要 |
| 缺資料就說清楚 | 行情過期、資料不足、額度／授權錯誤分別呈現；部分程式補正不冒稱全部由AI產生 |
| 下單由你決定 | 模型不具有草稿確認、送單或平倉工具；操作保持人工確認與後端重驗 |

介面另提供歷史案例／風險與來源範圍說明。歷史結果不是新單勝率；固定草稿快照不是即時更新。10/27新增的後續情境／草稿風險尚未接入本站，不能因這份說明可見就稱已上線。

呈現位置：交易對話 provider-label 的「回答原則」、使用指引內「助手如何回答」。WorkspaceDialog 維持工作台位置，內容捲動不推移工作區。數值與引用檢查不等於完整語意驗證，不能保證每段推論正確。
