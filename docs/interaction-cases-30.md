## 重跑方式

在 frontend/ 執行：

```powershell
node node_modules/tsx/dist/cli.mjs --test tests/interaction-corpus.test.ts
python -B -X utf8 tests/check_conversation_corpus.py
```

前者包含公開展示10句、提醒10句與1項清單完整性檢查；後者檢查正式解析10句。預期欄位在JSON中逐項比對，原草稿／規則不得被解析函式改寫。30句均已通過本輪程式驗證。

這是確定性程式測試，並非30句都逐句在瀏覽器操作，也不是 Groq 回覆品質或多人交易驗收。正式AI接通後，A仍需檢查相同輸入的引用、降級、權限與實際回覆。
